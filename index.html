Pick the kind of run you're doing:

  • Easy / recovery — low effort, short. Comfort weights cold more (you generate little heat). Typical: 30–60 min.
  • Tempo — sustained moderate-hard effort. Heat matters more than for easy. Typical: 40–60 min.
  • Intervals / VO2 — hard, short reps. Heat dumping is the limiter, so hot/humid hurts most; tolerates cold best. Typical: 45–60 min.
  • Long run — easy pace but long exposure. Cumulative heat matters, so it favors cooler windows a bit more than easy. Typical: 60–120+ min.
